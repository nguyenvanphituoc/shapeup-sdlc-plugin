# Changelog for solution-architect

| Version | Date | Changes |
|---------|------|---------|
| 1.2 | 2026-08-02 | **Both of this skill's files become markdown** (ADR-0001, unreleased). Its sole write surface is now `shapeup/<slug>/wiring-map.md` (frontmatter scalars + one `## Wiring` table carrying `entries[]`, per `contract-md.mjs`'s `WIRING_MAP` layout), and the profile it must read — never guess — is `shapeup/<slug>/project-profile.md`. Same rule as the scope contracts: a wiring map is design a reviewer should read in a PR, and the shared tier is markdown. The wire format is unchanged (`compile-order` parses the file and embeds the same object), so `trace-lint`'s reachability BFS, the Mermaid view and the spine fixtures see exactly what they saw before. Direct-write authority (bypassing `ingest-result`, the `scope-architect` precedent) and the ESCALATE-if-the-profile-is-absent rule are unchanged. One inherited consequence, shared with the scope contracts: the map is now hand-editable, and the mitigation ADR-0001 names for that (a `spec-lint` re-validation against `domain.schema.json`) is not implemented — a malformed hand-edit surfaces at `trace-lint` time as a missing edge, if at all. The invocation note also stopped using a bare `node kernel/verify/trace.mjs` — every script path a skill prints is now the fully-qualified `${CLAUDE_PLUGIN_ROOT}/…` form that `npx shapeup-sdlc init` actually grants in `permissions.allow`. |
| 1.1 | 2026-07-24 | **Design-intent reframe** — the skill runs at design time (GATE L1a.5, before any code exists) but was written as a build-time *verifier*, and that mismatch produced two defects. **(a) Fabricated coordinates:** it taught the worker to emit `entry_call_site: "main.js:42"` — a file:line for code that does not exist yet, and one parsed by nobody (trace-lint's reachability is an import-graph BFS from `ProjectProfile.entry_point` to `engine`; the Mermaid view reads `use_case`/`engine`/`affordance`; the slicer reads `wiring_seam`). `entry_call_site` is now **design intent**: the symbolic composition-root attachment named from the profile's `entry_point` + mechanism (`"src/server.ts — POST /checkout route"`), never an invented line — the concrete coordinate is a build-time fact. `domain.schema.json`'s field description was updated to match. **(b) Layer inversion:** Core-process step 4 made a pipeline-blind worker run the orchestrator-owned `harness verify trace` as mandatory craft — removed. The oracle stays the orchestrator's, run advisory at L1b (the same rule that keeps `harness verify t0` out of task-executor); the standalone preview moved to the Invocation block, labelled near-vacuous pre-build. Craft restated as the real architect job: engine assignment → integration-seam mechanism → composition-root attachment → affordance, with an unattachable engine surfaced via `deviations[]`/`escalates[]` instead of a code-traced red. Anti-rationalization rows retargeted (`main.js:42` fabrication; "I'll run trace-lint to check my map"). No schema-required field changed — `WiringEntry` still requires only `use_case` + `engine` — so trace-lint and the spine fixtures are untouched. |
| 1.0 | 2026-07-23 | Landed with the traceability spine (3d4a599) as the harness's 13th skill and the **reachability** half of the covers-closure oracle. Motivated by the audit's 631-line asset pipeline: 26 passing tests, **zero call sites**, unreachable from the running app — with five more scopes whose engines were never wired to a player. Authority: **sole writer** of the committed `wiring-map.json`, written **directly** (bypassing `ingest-result`) — the `scope-architect`/`scopes/*.json` precedent. Operation `wire` at ⏸ GATE L1a.5, between Orient (L1a) and Map Scopes (L1b), so the integration seam is front-loaded for the slicer — the missing input behind the round-1 substrate-expansion escalations ("declined by precedent"). Reads `project-profile.json` for the archetype-specific `entry_point` (a game's `main.js` is not a service's `src/server.ts`); ESCALATE if the profile is absent, never guess. Pure worker: WorkOrder in, wiring map + WorkResult out. |

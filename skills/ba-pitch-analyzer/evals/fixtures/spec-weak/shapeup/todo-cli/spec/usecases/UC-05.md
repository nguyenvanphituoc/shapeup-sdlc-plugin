# UC-05 — Remove todos

**Actor:** CLI user
**Deliverable type:** CLI (non-UI → oracle `process`)
**Engine:** the module that owns the removal flow.

## Steps
1. User runs `todo rm <selector...>` — e.g. `rm 3`, `rm 2-3 5`.
2. Every selector is resolved against the list as it was when the command started.
3. The selected items are removed together; the store is written once.

## Invariants
- **INV-08** — Removing several items resolves positions against the ORIGINAL list, so a batch
  removal never shifts the items it has not removed yet.
- **INV-09** — One bad selector refuses the whole batch and writes nothing.

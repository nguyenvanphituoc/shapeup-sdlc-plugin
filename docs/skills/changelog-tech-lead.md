| 1.7 | 2026-08-02 | **ADR-0001 + the ratchet and the receipt** (unreleased). Three things at once, and the third is a deliberate loss. **(a) One place that knows where files go.** `scripts/lib/paths.mjs` becomes the single source of truth for both roots and every generated path; test #45 fails if any file builds one otherwise. That is what turned a 90-file rename — 568 string literals plus 48 sites that built paths from `join()` segments, invisible to any grep — into a checkable change (it caught 7 sites a grep missed). The roots are now `shapeup/` (committed prose: shaping, spec, contracts, `REPORT.md`) and `.shapeup/` (gitignored structured state), on the rule *prose is the team's, structured data is the machine's*. `round-ledger.md` and `metrics/` move to LOCAL — both mutate mid-run, and a committed metrics shard keyed on `$HOSTNAME` only grows; the committed `gate-answers.json` lane is removed outright, because a committed set with `preset: ci` pre-approved GATE L4 ship sign-off for everyone who pulled. **(b) The build loop gets a pawl.** `t0-verify` gains `score()` (a vector: regressions, fixtures passed/total, db probe) and `better()` (lexicographic, strict — a tie is not better, because a tie that counts as improvement makes a sawtooth look like a ratchet), writes verdicts immutably to `t0/verdicts/r<R>-a<A>-t<T>.json` via exclusive create (invariant I4 — a retry lands *beside* its predecessor instead of overwriting it), and appends `t0/trials.jsonl`. BUILD stops branching on red/green and branches on `status`: **kept** (strictly better — including RED-BUT-IMPROVED, 2/5 → 4/5, which is the whole point) · **reverted** (not better; tree restored from the last kept snapshot — this subsumes the old seesaw `git stash` branch) · **rebased** (incomparable: a split or remap changed `fixtures_total`, so the baseline resets — not a verdict, not a failure) · **crash**. Orders carry `payload.trial_history` (last 8 trials, crossing the round boundary) where they carried one attempt's digested errors. The inner breaker gains a **stagnation** term at L0.9, `no_progress_k` (default 2 consecutive non-`kept` trials), because `attempt_budget` counts attempts and cannot see that the last two produced nothing; it queues the same GATE H proposal. **(c) `allow` gets a receipt, and GATE L2 gives up its denial.** Every enforcement point's failure signature used to equal its success signature — `exit 0`, empty stdout, which is also what "inspected and permitted" looks like; that indistinguishability is how 26 enforcement points sat inert behind 610 green checks. `hooks/lib/decision.mjs` makes `runHook` the only exit path and appends every decision to `.shapeup/decisions.jsonl`; fail-open is retained, now with evidence. `hooks/gate-l2.mjs` becomes **advisory** — it still reads the board from two independent sources and still names the unfinished tasks, but it emits a `systemMessage` instead of denying (hence the `warn` verdict, without which an advisory permit would be byte-identical in the log to a green board). The cost is stated in ADR-0001 rather than hidden: nothing now prevents EVAL on a half-green board, a defect measured in the island-escape run (16/20 task files still `status: ready`), and the README's headline claim changes — `validate-envelope` becomes the flagship enforced gate. Also: `ship-report.mjs` freezes `shapeup/<slug>/REPORT.md` once at L4 from artifacts (the run trace is gitignored, so this is all a reviewer sees); `stats` gains `--ratchet` and `--hooks`, harvested into the metrics shard at SHIP or lost; all 15 entry points take flags through the typed `lib/argv.mjs` (`--round` with no value used to write `rNaN-a1.json` and exit 0, leaving the evaluator's mandatory citation unresolvable); and all 31 script call sites in `SKILL.md`/`references/` are the literal `${CLAUDE_PLUGIN_ROOT}/…` form, with the prose note that asked the model to do the substitution **deleted** — it was a prompt-carried invariant sitting under the mechanism built to forbid those, and its failure mode was already measured at 26 approval denials in one session. |
| 1.6 | 2026-07-29 | **The enforcement layer was inert under an ordinary install, and every gate reported success** (v1.4.1). The entry-point guard, in two broken spellings across 26 files, compared `import.meta.url` against `process.argv[1]` — false under any symlinked directory (macOS `/var`, nvm, pnpm, Homebrew) or any path with a space, so the body was skipped and the script **exited 0 with no output**. It hit all seven guarded hooks plus `init-run`, `gate-answers`, `budget-check`, `t0-verify`, `fit-check`, `aegis-digest`, the four oracles, and — sharpest — `validate-envelope`, `compile-order`, `ingest-result`, `run-snapshot`, `trace-lint`, `board-derive`, `spec-lint`, `stats`. Priced on the benchmark: `init-run.mjs` is GATE L0.1 and returned nothing, so the orchestrator could not tell "the run opened" from "nothing happened" and spent 82–120 turns on forensics before its first write, at $4.57–$10.36 for 0/3 of the gap. Fixed by `lib/is-main.mjs` and held by a **structural** rule (the two identifiers may not share a line) plus `tests/structural/11-is-main.mjs`, which executes every guarded entry point through a symlinked directory and a directory with a space — the shape the old suite never used, which is how 610 green checks coexisted with an inert layer. Also in this release: **`init-run`'s already-open-run refusal becomes a resume path** (exit 3 with the run's state, not a dead end) and `SKILL.md` gains **Step 1c** naming which phase to re-enter (`orienting`→L1a, `mapping`→L1b, `building`→L2, `evaluating`→L3) — the branch had no procedure anywhere; the prose ratchet was raised 450 → 460 to pay for it, deliberately, with the reason recorded in the test. And three reflexes that fired on ordinary work were fixed before release, each a regression against 1.4.0: a stale `active-scope` pointer no longer reads as an open run (it must be corroborated by a mid-run ledger); `gate-zerowork` anchors `/ship` to the start of a message (asking *about* `/ship` is not dispatching it); and `anti-rationalization` became tense-aware (an unfinished board is the *premise* of "I'll now run the evaluator", not a contradiction of it). | 1.5 | 2026-07-27 | **Five mechanisms against measured benchmark failures** (v1.4.0). The harness was the only arm on its benchmark that failed to finish a feature. Each fix moves an invariant out of prose and into the runtime — each was in prose precisely because prose is what gets dropped, paraphrased or summarised. **`init-run.mjs` (GATE L0.1)** is now the orchestrator's first tool call, before any narration: it writes `receipt.json`, `intake.md` (requirement verbatim + SHA-256), `harness-run.md` and `active-scope`, supplying the fact the system lacked — *a run started*. **`gate-zerowork.mjs`** blocks at `Stop` a session that dispatched this skill and left no receipt: given a valid spec, the orchestrator had returned a description of eleven gates and ended — 29% acceptance, 10 escaped defects, 5/5 with zero variance, reading like a clean run; the two existing guards structurally could not see it (one is scoped to an active run, the other matched past-tense claims while narration is future-tense). **`gate-answers.mjs`** turns sign-off — the last load-bearing invariant carried in prose — into a schema-validated answer set (`ci`/`guarded`/`interactive`) the orchestrator branches on by exit code (0 cross, 4 stop for the PO, 5 abort); not "gates off": every gate still blocks and still records a decision, but the decision's *source* is named. **The third breaker** (`budget-check.mjs` + `hooks/gate-deadline.mjs`) covers the axis the other two cannot see — both count events, so neither notices one round running for half an hour (F3: 327 turns, zero stall signals, killed from outside having shipped nothing, including scopes already green).

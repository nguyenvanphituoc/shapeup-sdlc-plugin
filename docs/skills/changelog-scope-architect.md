# Changelog for scope-architect

| Version | Date | Changes |
|---------|------|---------|
| 1.1 | 2026-08-02 | **The contract becomes markdown — the format change, not a craft change** (ADR-0001, unreleased). `scopes/<scope-id>.json` → `shapeup/<slug>/scopes/<scope-id>.md`: frontmatter for the scalars and `[a, b]` lists, a `## Affordances` table for the one array-of-objects field (`affordance_manifest`), and a short `## Why this slice` paragraph. The reason is the ADR's shared-tier rule — a scope contract is *low-level design a reviewer should read in a PR*, and it was the only thing in the committed tree they could not. Full YAML would have cost a dependency against the zero-dependency rule every script here holds, so the format reuses the two parsers the codebase already had (`trace-lint.parseRequirements`, `compile-order.ledgerDecisions`). **Markdown is the on-disk form; JSON is still the wire form** — `compile-order` parses the file and embeds the same object in `payload.scope_contract`, so the envelope, its schema, and `validate-envelope` are untouched, and so is every downstream reader (sandbox whitelist, `t0-verify` fixtures, `spec-lint` disjointness). Two new obligations for this skill: regeneration must **preserve prose under headings it does not own** (a reviewer's note in `## Why this slice` survives a remap), and a contract is now hand-editable, which is a real loss of a guarantee: it used to be machine-written and schema-validated on every write. ADR-0001 and `contract-md.mjs`'s header both name the mitigation — *`spec-lint` re-validates every parsed contract against `domain.schema.json`* — but that pass is **not in `spec-lint.mjs`** as shipped; its rules are still PA1/PA2/DISJOINT/STRUCTURE/TIER-DIRECTION/TASK. Treat the mitigation as owed, not delivered. Sole-writer authority, import-graph slicing, topology classification, fixtures and supersede-never-delete are all unchanged. Earlier (2026-07-24): description compressed to trigger surface + the `NOT for …` boundary against `ba-pitch-analyzer` and `scope-hammer`. |
| 1.0 | 2026-07-13 | Extracted from ba-pitch-analyzer Phase 6b + `--remap`/`--split` (plan §8.4): a distinct skill because it holds a distinct authority (sole writer of scope contracts) and a distinct failure mode (PA1 directory-thinking). Craft: import-graph slicing by flow, topology classification, affordance-manifest derivation, fixture authoring, supersede-never-delete. PA1/PA2/disjointness linting is mechanical (`spec-lint.mjs`); hill_phase is never authored (DD-10). Pure worker: WorkOrder in, contracts + WorkResult out. |

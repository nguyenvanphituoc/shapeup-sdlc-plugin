## 1. The three cuts

v4 is one direction taken three times: move work out of scripts that sequence the run and into the host's own mechanisms, keep only what a
prompt cannot be trusted to do.

| Cut | What it did | Outcome | Record |
|---|---|---|---|
| **1. Single loop** (2026-11-07) | the run stopped being a launched workflow script; `building` became a loop in the PO's own session, planning steps folded into a fence-only `plan` activity, five skills and a courier deleted | every activity done with a real run behind it; the release (`v4.0.0`) was left local by the PO's decision | `execution-2026-11-07.md`, ADR-0004 |
| **2. Native first** (2026-11-08, S1–S2) | workers became plugin subagents (`agents/*.md`, `skills:` preload), the dispatch receipt came from the host, the Stop hook and several kernel verbs went | S1 and S2 each gated on a real run that shipped; one defect in S2 was found by S3 and fixed | `execution-native-first-2026-11-08.md`, ADR-0005 |
| **3. Engine removed** (S3 measured, then removed) | `compile`, `reduce`, `probe`, three `verify` verbs and the helper libraries deleted; the loop sequences itself | the removal was applied after S3 measured the engine ahead; one real run on the result shipped, after a resume | same record, ADR-0006 |

A fourth, small change follows from the real run on the third: GATE L4 refuses `ship` over a QA hunt the run owed and never ran.

## 4. What the removal kept, and what it handed to the loop

Kept and executed by tests: the receipt (`init run`), the gate resolver (`gate`, including the L2 empty-board refusal and the L4 census and
QA refusals), the T0 witness (`verify t0`), the write fence (`sandbox-guard`, armed and retired by `order open | close`) and the dispatch
receipts, plus `verify envelope`, `safety-spine`, the four oracles and the installer.

Moved from a script to the loop's own discipline, checked only by the PO and the evaluator: choosing the next step, applying a worker's
result to the board, linting the spec, counting attempts against the budget, building and launching before EVAL, the census and the ship
report. `AGENTS.md` says so in its first section.

- A second repetition of the real run was not made; the three self-disclosed defects and the QA refusal are unexercised by a run.
- The domain registry still describes some records the engine wrote. The T0 ratchet's snapshot holds tracked files only; a revert does not
  remove a file an attempt created (predates v4).
- Agents use `model: inherit`, so the launch record's model is intent and the dispatch receipts name the model that ran.
- The L3 gate prints its "loop" note over a PASS; the ledger records the PASS correctly.

# UC-12 — Import a store

**Actor:** CLI user
**Deliverable type:** CLI (non-UI → oracle `process`)

## Steps
1. The user runs the command this use case names.
2. The store is read, the change is applied, and the result is printed.
3. Bad input is refused on stderr with a non-zero exit, and nothing is written.

## Invariants
- **INV-12.1** — `wl import <file>` replaces the store after validating it.
- **INV-12.2** — A malformed file leaves the existing store untouched.

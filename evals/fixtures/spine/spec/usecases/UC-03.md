# UC-03 — Search todos

**Actor:** CLI user
**Deliverable type:** CLI (non-UI → oracle `process`)
**Engine:** the module that owns the search flow.

## Steps
1. User runs `todo search <needle...>`.
2. Items whose text contains the needle, case-insensitively, are printed in list format.
3. No match prints `no todos` and exits 0.

## Invariants
- **INV-05** — Search never mutates the store.

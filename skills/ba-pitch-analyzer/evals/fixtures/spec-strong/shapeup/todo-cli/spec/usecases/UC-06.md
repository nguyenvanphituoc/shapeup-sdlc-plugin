# UC-06 — Archive completed todos

**Actor:** CLI user
**Deliverable type:** CLI (non-UI → oracle `process`)
**Engine:** the module that owns the archive flow.

> This repository contains more than one module that reads as an archive implementation. Only the
> one the running CLI can actually reach counts as this use case's engine.

## Steps
1. User runs `todo archive`.
2. Every item already marked done is dropped from the store.
3. The count of archived items is printed.

## Invariants
- **INV-10** — `archive` leaves every not-done item in place, in its original order.

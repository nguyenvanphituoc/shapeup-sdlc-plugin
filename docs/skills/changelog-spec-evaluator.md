# Changelog for spec-evaluator

| Version | Date | Changes |
|---------|------|---------|
| 1.4 | 2026-08-02 | **ADR-0001 consumer layout + a typed argv boundary** (unreleased). The evaluation substrate is `.shapeup/<slug>/evaluation/**` and the spec it grades against is `shapeup/<slug>/spec/` — the report and its evidence stay run-trace *while they mutate*, and their conclusions are frozen at GATE L4 into the committed `shapeup/<slug>/REPORT.md` (verdict + refuted criteria, QA findings by lens, T0 summary, adjudicated decisions, cut list). That report is the only run evidence a teammate sees, `harness reduce ship` derives its evidence from the files this skill and `t0-verify` wrote (the eval report, the immutable verdict artifacts, the trial ledger, the board), never from the orchestrator's summary; the verdict itself is passed in as `--verdict PASS\|FAIL\|not-evaluated`, i.e. copied from this skill's WorkResult rather than re-judged — the single-judge rule survives the freeze. `harness reduce verdict` takes its argument through the typed `lib/argv.mjs` contract instead of a bare `process.argv[2]`. Craft untouched: skeptical posture, criteria-from-committed-spec, the T0 citation with recomputed sha256, affordance-only UI grading. |
| 1.3 | 2026-07-28 | **`harness reduce verdict` was inert under a symlinked install** (v1.4.1). It carried the entry-point guard's second broken spelling — `resolve()` normalises a path but does not resolve symlinks — so under nvm, pnpm, Homebrew, macOS `/var`, or any symlinked checkout it skipped its body and **exited 0 with no output**, which is indistinguishable from a clean run. Fixed with `lib/is-main.mjs` (resolved URL vs. resolved URL) and made structural: no file may compare `import.meta.url` against `process.argv[1]` on one line. |
| 1.2 | 2026-07-26 | **Playwright becomes a lazy dependency** (v1.4.0, P1-1). The plugin-level dependency is gone; this skill preflights the browser at the **first `[ui]` criterion** and fails *that probe* with the fix named. It never auto-installs and never silently skips — an unverifiable `[ui]` AC is a FAIL, not a PASS, which is the judge-purity rule applied to its own tooling. Non-UI runs now complete with no browser installed. |
| 1.1 | 2026-07-24 | **Script co-location** (v1.3.0, skills-optimization). `harness reduce verdict` moves `scripts/shapeup-sdlc/` → `skills/spec-evaluator/scripts/`, matching the v1.0 rule that a runtime script lives inside the skill that owns it — the ledger reader is the judge's tool, and a shipped skill must be self-contained. Description compressed to trigger surface plus the posture line ("absence of evidence is a FAIL"). |
| 1.0 | 2026-07-13 | **Pure-skill rewrite** (plan P3): input is a WorkOrder (`--order`) carrying spec folder, feature, dimensions, run command, and T0 artifact paths — GATE V0's locate/load plumbing (path resolution, local-task-file glob, run-state read) is deleted; the caller pins context. All shared-state writes removed (D6): the `.verdicts` JSONL append (old B.0), task-file annotation (B.2), AC un-ticking (B.2b), and run-state update (B.3) now return as `verdict.criteria[]` / `verdict.refuted[]` in the WorkResult for `harness reduce ingest` to apply. Kept as craft: skeptical posture + anti-leniency, criteria-from-committed-spec rule (v0.9), probe design, re-probe/confidence/flip grammar, hard thresholds + halo ban, T0-citation requirement with recomputed sha256 (v0.8), affordance-only UI grading, the pluggable dimension model, single-judge authority. New: anti-rationalization table + verification checklist. 462 → ~230 lines. |
| 0.x | 2026-06/07 | Gate-pipeline versions (GATE V0–V3, dimensions, verdict ledger, T0 citation, local-tasks grading move). Superseded by the pure-worker contract; see git history. |

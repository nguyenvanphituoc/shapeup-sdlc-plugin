# UC-02 — List todos

**Actor:** CLI user
**Deliverable type:** CLI (non-UI → oracle `process`)
**Engine:** the module that owns the list flow.

## Steps
1. User runs `todo list`.
2. Every stored item is printed as `<n>. [ ] <text>` (or `[x]` when done).
3. An empty or absent store prints `no todos` and exits 0.

## Invariants
- **INV-03** — `list` succeeds against a store file that does not exist yet.
- **INV-04** — The number shown beside an item is its 1-based position in the store array.

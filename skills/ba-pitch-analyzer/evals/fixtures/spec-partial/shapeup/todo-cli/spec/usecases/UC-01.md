# UC-01 — Add a todo

**Actor:** CLI user
**Deliverable type:** CLI (non-UI → oracle `process`)
**Engine:** the module that owns the add flow.

## Steps
1. User runs `todo add <text...>`.
2. The text is validated (non-empty, at most 200 characters).
3. The item is appended to the store and a confirmation line is printed.

## Invariants
- **INV-01** — An empty or whitespace-only text is refused, non-zero, without writing the store.
- **INV-02** — A successful add appends exactly one item and leaves the others untouched.

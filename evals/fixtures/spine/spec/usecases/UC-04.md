# UC-04 — Mark todos done

**Actor:** CLI user
**Deliverable type:** CLI (non-UI → oracle `process`)
**Engine:** the module that owns the completion flow.

## Steps
1. User runs `todo done <selector...>` — e.g. `done 2`, `done 2-4`, `done 1 3 5`.
2. Every selector is resolved against the list as it was when the command started.
3. Each selected item is marked done; the store is written once.

## Invariants
- **INV-06** — One out-of-range or malformed selector refuses the whole batch and writes nothing.
- **INV-07** — Marking an already-done item is a no-op, not an error.

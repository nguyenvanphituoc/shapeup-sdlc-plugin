# Changelog for ba-pitch-analyzer

| Version | Date | Changes |
|---------|------|---------|
| 4.3 | 2026-08-02 | **ADR-0001 consumer layout + the delegates get libraries** (unreleased). Roots renamed (`shapeup/<slug>/` shared, `.shapeup/<slug>/` local), so the `coverage` registry is `shapeup/<slug>/requirements.md` and the board is `.shapeup/<slug>/tasks/`; scope contracts referenced in reconcile are `scopes/<scope-id>.md`, not `.json`. The two delegates stop hand-rolling what the harness now owns: `harness reduce board` and `harness verify spec` resolve every path through `lib/paths.mjs` (test #45 forbids constructing one any other way), parse contracts through `lib/contract-md.mjs` (`readAllContracts` — which also fixed a defect the new tests caught: a `.md`/`.json` pair counted as two scopes), and take flags through the typed `lib/argv.mjs` contract (reject before anything runs, exit 2, machine-readable reason). **Gap, stated rather than papered over:** the markdown move makes contracts hand-editable, and both ADR-0001 and `contract-md.mjs`'s own header name the mitigation as *"`spec-lint` re-validates every parsed contract against `domain.schema.json`"* — that pass does not exist in `harness verify spec`, which still runs only PA1/PA2/DISJOINT/STRUCTURE/TIER-DIRECTION/TASK. Until it lands, a hand-edit that widens `allowed_file_substrate` is caught by the disjointness rule only if it collides with another scope. Both invocations in `SKILL.md` are now the fully-qualified `${CLAUDE_PLUGIN_ROOT}/skills/ba-pitch-analyzer/scripts/…` form — the bare `node scripts/…` form resolved to nothing from the project cwd and matched no `permissions.allow` rule. |
| 4.2 | 2026-07-28 | **Both delegates were inert, and said nothing** (v1.4.1). `harness reduce board` and `harness verify spec` carried the second broken spelling of the entry-point guard — `resolve(process.argv[1]) === fileURLToPath(import.meta.url)`, which normalises a path but does **not** resolve symlinks. Under any symlinked install path (macOS `/var`, nvm, pnpm's store, Homebrew, a symlinked checkout) the comparison is false: body skipped, **exit 0, no output**. These are the two scripts AGENTS.md names as this skill's graph-math and audit delegates — so the PA1/PA2/disjointness audit and the unlocks recompute both reported success by producing nothing. Fixed via `lib/is-main.mjs` (resolved URL vs. resolved URL); the guard is now a structural test rather than a blocklist — `import.meta.url` may not appear on the same line as `process.argv[1]` anywhere in the tree, so no unseen spelling can come back. |
| 4.1 | 2026-07-24 | **Fifth operation: `coverage`** (traceability spine, v1.3.0). Extracts atomic customer-requirement clauses into the SHARED `requirements.md` registry (`$defs/RequirementClause`) — the covers-closure half of `trace-lint`. One testable clause per row: the audit's dropped requirements ("side-step OR lure enemies into traps") were *lost inside* a bigger sentence, which is why compound splitting is craft here and not formatting. REQ-ids are assigned once and frozen (they behave like `scope_id`, never `TASK-NNN` — every `covers:` link rots otherwise): re-running appends, a removed clause is marked `CUT (PO-approved)`, nothing is renumbered or deleted, and only the PO sets `CUT`. The REQ source defaults to the pitch, overridable via `payload.requirements`; the source itself is frozen, the registry is the derived file. Also: `TaskRef.acceptance_criteria` became the additive union `string \| {text, covers?}`, so legacy string boards keep parsing. Description compressed the same day to trigger surface + output shape. |
| 4.0 | 2026-07-13 | **Pure-skill rewrite** (plan P3/§8): 670 lines / 15 flags / 12 prose modes → one craft + 4 operations selected by the WorkOrder; mode write-rules became substrate whitelists enforced by the sandbox hook. Mechanical halves extracted: Phase 7a self-audit + PA lints + 7c parse steps → `harness verify spec` (self-grading removed — judge-purity); Phase 7b graph math + v3.3 unlocks recompute + drift check + Appetite Guard arithmetic → `harness reduce board` (HAMMER pause is the caller's gate). Phase 0 scoring arithmetic retired; the lens judgment stays as one paragraph. Worker state deleted (run-state.md writes, pitch_hash cache, human_edited_files, discovered_rounds) — stateless by construction, D6 closed. Phase 6b scope contracts moved to the new `scope-architect` skill (distinct authority: sole writer of scopes/*.json). Craft kept verbatim: DDD decomposition, contract two-pass, UC/Test-Surface derivation + anti-invention rule, task atomicity + contract-first + AC Trigger Matrix, reconcile discipline (frozen Steps, continue-numbering, new-actor STOP). New: anti-rationalization table + verification checklist. |
